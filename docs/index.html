          セッション

            並べているライブ・過去配信・開始位置・マーカー・レイアウトを、このブラウザに保存します。メンバーとグループは左の一覧に別に保存されています。

            設定

            キー割り当て

            右の枠を押してから新しいキーを押します。Esc で取り消し、Backspace で解除。1〜9 は「その動画の音だけ出す」で固定です。

            使い方

            1. 登録上の欄に Twitch のチャンネル名か URL を入れて Enter。ライブが表示され、左のメンバーに登録されます。複数まとめて貼っても入ります。
            2. 呼び出す左のメンバーを押すとスイッチが入り、その人のライブが並びます。もう一度押すと消えます。
            3. グループライブを並べた状態で「今の画面を保存」を押して名前を付けると、そのグループのスイッチ1つで全員をまとめて出し入れできます。メンバーの「…」からグループへの出し入れもできます。
            4. ファイル左上の矢印ボタンで、メンバーとグループを JSON ファイルに書き出し・読み込みできます。別の PC や仲間に渡すときに使います。
            5. 過去配信twitch.tv/videos/… の URL を入れると、下のタイムラインで同期再生できます。棒を左右にドラッグするか、右の ±ボタンで同じ瞬間に合わせます。

            キー

            できないこと

            • スイッチが入っていないメンバーが配信中かどうかは分かりません（Twitch の公式の仕組みでは、ログインや鍵なしに調べられないため）。スイッチを入れると表示されます。
            • Twitch 以外のサイトと、Twitch のクリップには対応していません。
            • Twitch の埋め込みプレーヤーは再生速度を変えられないため、過去配信を 1× 以外で見ると位置合わせのシークで追いかけます。
            • ブラウザによっては、音ありの自動再生が止められます。そのときは動画の枠内の再生ボタンを一度押してください。
            • Twitch は、枠が小さすぎる（400×300 未満）ときや、映像の上に描画が残っているときに自動再生しないことがあります。並べる数を減らすか、描画を消してください。
            • iPhone / iPad では、複数の動画を音ありで同時に再生できないことがあります。ミュートなら再生できます。
