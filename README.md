# VOD

複数の動画を並べて、ひとつのタイムラインで同期再生するブラウザツール。
試合の複数視点の見比べや、プレーの振り返りに使う。インストールも登録もいらない。

**https://ayukari.github.io/vod/**

## 読み込めるもの

| 種類 | 例 |
|---|---|
| YouTube | 動画・ライブのアーカイブ（`watch?v=` / `youtu.be/` / `shorts/` / `live/`） |
| Twitch | 過去の配信（`twitch.tv/videos/…`） |
| Vimeo | 公開・限定公開の動画 |
| ニコニコ動画 | `sm` / `so` で始まる動画（試験対応） |
| 直リンク | `https://…/*.mp4` `.webm` `.mov` `.m3u8` |
| 手元のファイル | MP4 / WebM など、ブラウザで再生できる形式 |

URL に `?t=1m30s` などの時間が付いていれば、その位置を開始位置として使う。

Kick、X（Twitter）、TikTok、Instagram、Twitch のクリップなどは、外から再生位置を操作する仕組みがないため同期できない。

## 使い方

1. 上の欄に URL を貼り付けて Enter（複数行もまとめて入る）。ファイルは画面にドロップ。
2. 下のタイムラインの棒を左右にドラッグするか、右のクリップ一覧の ±ボタンで開始位置を合わせる。
3. 再生・停止・シーク・コマ送りは全部の動画に同時にかかる。
4. 描画・マーカー・スクリーンショット。状態はセッションとして保存でき、共有リンクで人に渡せる。

キー操作は画面右上の「?」から確認・変更できる。

## できないこと

- YouTube・Twitch・Vimeo・ニコニコの映像は、ブラウザの仕組み上スクリーンショットに写らない（描画・名前・時刻は写る）。
- Twitch とニコニコは再生速度を変えられないため、1× 以外では位置合わせのシークで追いかける。
- 直リンク・m3u8 は、配信元がブラウザからの読み込みを許可している場合だけ再生できる。
- iPhone / iPad では、複数の動画を音ありで同時に再生できないことがある（ミュートなら再生できる）。
- ニコニコ動画は公式に公開されていない仕組みを使っているため、将来動かなくなる可能性がある。

## データの扱い

サーバーを持たない静的なページで、読み込んだ動画・メモ・セッションはブラウザの中（localStorage）だけに保存する。
共有リンクの中身は URL の `#` 以降に入っていて、サーバーには送られない。

## 手元で動かす

Node.js が入っていれば、`start.bat` をダブルクリック（または `node server.js --open`）で http://localhost:5178 が開く。
公開用のファイルは `docs/` にあり、GitHub Pages がそのまま配信している。
