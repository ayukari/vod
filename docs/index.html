      共有リンク

      このリンクを開くと、同じ動画・開始位置・マーカー・レイアウトで始まります。

      セッション

        このブラウザに保存されます。手元のファイルは名前だけを覚えるので、開いたあとに選び直してください。

        設定

        キー割り当て

        右の枠を押してから新しいキーを押します。Esc で取り消し、Backspace で解除。1〜9 は「その動画の音だけ出す」で固定です。

        使い方

        1. 追加上の欄に URL を貼り付けて Enter。複数行をまとめて貼っても入ります。ファイルは画面にドロップ。
        2. そろえる下のタイムラインの棒を左右にドラッグするか、右のクリップ一覧の ±ボタンで、同じ瞬間が重なるように開始位置を合わせます。棒は 0・再生位置・ほかの動画の端・マーカーに吸い付きます（Alt で解除）。
        3. 見る再生・停止・シーク・コマ送りは全部の動画に同時にかかります。
        4. 残す描画、マーカー、スクリーンショット。状態はセッションとして保存でき、共有リンクで人に渡せます。

        キー

        できないこと

        • YouTube・Twitch・Vimeo・ニコニコの映像はブラウザの仕組み上スクリーンショットに写りません。描画・名前・時刻は写ります。
        • Twitch とニコニコは再生速度を変えられないため、1× 以外では位置合わせのシークで追いかけます。
        • Kick、X、TikTok、Instagram、Twitch のクリップなど、外から再生位置を操作する仕組みがないサイトは同期できません。
        • 直リンク・m3u8 は、配信元がブラウザからの読み込みを許可している場合だけ再生できます。
        • iPhone / iPad では、複数の動画を音ありで同時に再生できないことがあります。ミュートなら再生できます。
        • ニコニコ動画は公式に公開されていない仕組みを使っているため、将来動かなくなる可能性があります。
