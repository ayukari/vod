# VOD

Twitch のライブを並べて見るためのブラウザツール。
チャンネルを一度登録すれば、次からはスイッチ1つで呼び出せる。グループを作れば、スイッチ1つで全員まとめて出し入れできる。
インストールも登録もいらない。

**https://ayukari.github.io/vod/**

## 使い方

1. 上の欄に Twitch のチャンネル名（または `twitch.tv/名前` の URL）を入れて Enter。ライブが表示され、左の「メンバー」に登録される。複数まとめて入れてもよい。
2. 次からは、左のメンバーを押すだけでスイッチが入り、その人のライブが並ぶ。もう一度押すと消える。
3. ライブを並べた状態で「今の画面を保存」を押して名前を付けると、グループになる。グループのスイッチ1つで全員をまとめて出し入れできる。メンバーの「…」からグループへの出し入れや名前の変更もできる。
4. 左上の矢印ボタンで、メンバーとグループを JSON ファイルに書き出し・読み込みできる（別の PC や仲間に渡すとき用）。
5. 過去の配信（`twitch.tv/videos/…`）を入れると、下のタイムラインで同期再生できる。棒のドラッグや ±ボタンで開始位置を合わせる。

キー操作は画面右上の「?」から確認・変更できる。

## できないこと

- スイッチが入っていないメンバーが配信中かどうかは分からない。Twitch の公式の仕組みでは、ログインや鍵なしに調べられないため。スイッチを入れると LIVE / OFF が表示される。
- Twitch 以外のサイトと、Twitch のクリップには対応していない。
- Twitch の埋め込みプレーヤーは再生速度を変えられないため、過去配信を 1× 以外で見ると位置合わせのシークで追いかける。
- 枠が小さすぎる（400×300 未満）と、Twitch が自動再生しないことがある。
- iPhone / iPad では、複数の動画を音ありで同時に再生できないことがある（ミュートなら再生できる）。

## データの扱い

サーバーを持たない静的なページで、メンバー・グループ・セッションはブラウザの中（localStorage）だけに保存する。
共有リンクの中身は URL の `#` 以降に入っていて、サーバーには送られない。

## 手元で動かす

Node.js が入っていれば、`start.bat` をダブルクリック（または `node server.js --open`）で http://localhost:5178 が開く。
公開用のファイルは `docs/` にあり、GitHub Pages がそのまま配信している。
